# 搜狗词库清理工具（sogou-dict-cleaner）

清理搜狗输入法的用户词库：筛出乱码、生僻字、繁体字、拼音对不上的词、随手输入记下的短语、人名等，导出可以直接「恢复」回搜狗的干净词库。

搜狗用久了，用户词库里会积累很多没用的词条：「㥒쮤」这样的乱码、「埥䤅靨」这样字和读音完全对不上的汉字乱码、「我很喜欢喝」这样顺手记下的短语。打字时它们偶尔会冒出来，搜狗里又没法批量删除。这个工具直接处理搜狗导出的备份文件（`.bin`）。

## 网页版（推荐）

在线使用：**https://sogou-clean.pages.dev**

也可以直接打开本地的 `web/index.html`。点「打开文件」或把备份文件拖进页面即可。**文件只在浏览器里处理，不会上传。**

> [!WARNING]
> 用户词库里有你打过的人名、地址、账号、聊天内容等大量个人信息，非常敏感。请确认地址栏是 **sogou-clean.pages.dev**（官方网址只有这一个），不要在来历不明或仿冒的网站上打开词库文件。网页在其他域名下打开时会显示警告。

1. 在搜狗输入法「偏好设置 › 词库 › 中文用户词库」里点「导出/备份」，得到一个 `.bin` 文件。
2. 在网页里打开它，挑出要删的词。
3. 点「导出干净词库」，下载 `.bin`，在搜狗里用「恢复（完全覆盖）」选择它。

**原始备份请留好。** 恢复会完全覆盖当前词库，有问题时用原始备份再恢复一次即可。

### 界面

- **现有词库**（左）：词库里的所有词。
- **备选移除**（右上）：可疑的词先放在这里，等你逐条决定。
- **确认移除**（右下）：导出时会被删掉的词。

词只能按「现有词库 → 备选 → 确认移除」的顺序往移除方向走，不能从现有词库直接移除，以免误删。每行右侧有移动按钮：现有词库是「备选 →」，备选是「← 保留」「移除 ↓」，确认移除是「← 保留」「↑ 备选」。在已选中的多行上点按钮，会作用于整个选区。每行最前面有勾选框，点一下单独选中或取消这一行；表头的勾选框和栏头的「全选」会选中这一栏当前显示的所有词。

### 筛选

筛选栏的标签可以组合使用：点一下选中，再点一下取消。选中多个标签时，可以选「满足任一」或「全部满足」；另外还能限定词频和字数范围，比如「非常用词 + 词频 ≤ 1」「人名 + 重复词 + 全部满足」。

筛选栏下面会把当前条件写成一行表达式，例如 `(生僻字 OR 次常用字) AND 词频 ≤ 1`；选中「重复词」「叠词」时，这一行还会附上它们的说明。

筛选只作用于**现有词库**；备选和确认移除两栏始终显示全部内容，搜索框则同时作用于三栏。筛出来后在现有词库点「全选」，再点「移到备选 →」。

| 标签 | 说明 |
|---|---|
| 乱码 | 含非汉字、非 ASCII 的字符，或文字无法解码 |
| 汉字乱码 | 全是冷僻汉字，读音也对不上，如「埥䤅靨」读作 he kuang hai |
| 生僻字 / 次常用字 | 含 GB2312 以外的字 / 含 GB2312 二级字 |
| 繁体字 | 含繁体字（依据 OpenCC 繁简字表：有不同于自身的简体写法的字） |
| 拼音不符 | 字数和音节数不一致（例如拼音里存了好几次输入尝试，这种词按正常拼音打不出来），或某个字的读音在整本词库里只出现在这个词中 |
| 非常用词 | 两字及以上的汉字词，在常用词典（jieba 分词词典，约 34 万词）里查不到，多是随手输入记下的短语 |
| 人名 | 姓 + 名的组合，规则比较粗略 |
| 英文数字、多拼音 | 含字母或数字；同一个词以多种拼音出现 |
| 重复词 | 同一个词出现了多次（如两条「红外除尘」）。词频最高的一条不标记，其余都标记，移除后只留一条 |
| 零词频 | 词频为 0 |
| 叠词 | 同一片段重复（如「闭包闭包」「看一下看一下」），或同一个字连续 4 次以上 |

读音判断不依赖外部字典，而是用整本词库自身做参照：某个字以某个读音出现在多少个词里。所以词库越大，判断越准。

拼音后面如果带括号，括号里是**实际输入的拼音**，比如「白平衡 bai ping heng (bai ping h)」表示当时是用简拼打出来的。只有和词条拼音不同时才显示。

表格里的「时序」（只在现有词库显示）是词条记录的相对时间（伪时间），数值越大越近。搜狗要靠另一个映射文件才能把它换算成真实时间，而这个文件不在备份里，所以只能用来大致排先后。

### 操作

- 单击选择，<kbd>⇧</kbd> 点击连选，<kbd>⌘</kbd> 点击或点勾选框加选，<kbd>⌘A</kbd> 全选，<kbd>↑</kbd><kbd>↓</kbd> 移动光标
- <kbd>Delete</kbd> 往移除方向移动一步，<kbd>R</kbd> 保留，<kbd>B</kbd> 移到备选，双击一行也会移动
- <kbd>⌘Z</kbd> 撤销，<kbd>⌘F</kbd> 搜索（支持 `/正则/`；拼音带空格时按完整音节匹配），<kbd>⌘O</kbd> 打开文件
- 点表头按该列排序

挑选进度和筛选条件保存在浏览器本地，下次打开同一个备份会接着上次的状态。备选栏里没处理的词，导出时会保留。

### 部署成静态网站

`web/` 目录就是完整的网站，不需要构建。在线版部署在 Cloudflare Pages 的 `sogou-clean` 项目上，更新网站：

```bash
npx wrangler@4 pages deploy web --project-name sogou-clean --branch main
```

拼写错误的旧网址 `sougou-clean.pages.dev` 是另一个 Pages 项目，只部署了 `redirect/_redirects`，会把所有请求 301 跳转到 `sogou-clean.pages.dev`（保留路径）。它一般不需要再更新。

也可以在 Cloudflare 后台把 Pages 项目连接到 GitHub 仓库：构建命令留空，输出目录填 `web`，之后每次推送都会自动部署。

`web/data.js`（常用词表和繁体字表，约 3.7 MB，压缩传输约 1.3 MB）由 `python3 tools/build_data.py` 生成。页面打开后会在后台加载它。

## 命令行

只用 Python 3 标准库，不需要安装依赖。

| 命令 | 作用 |
|---|---|
| `python3 sogou_dict.py export 备份.bin [输出.txt]` | 导出为文本，每行 `词<Tab>拼音<Tab>词频`，拼音之间用空格分隔 |
| `python3 sogou_dict.py clean 备份.bin 输出.bin` | 一步删除乱码词条，直接生成可以恢复的 `.bin` |
| `python3 sogou_dict.py rebuild 备份.bin 编辑后.txt 输出.bin` | 按编辑后的文本重建 `.bin`，可以删词、改词频、加词 |
| `python3 sogou_dict.py check 文件.bin` | 按搜狗加载时的逻辑检查文件头 |

`clean` 只删「乱码」：保留只由汉字（含扩展区）、可见 ASCII 字符和「〇」组成的词，以及能正常解码的词。更细的挑选请用网页版。

## 恢复失败？先检查文件权限

如果搜狗提示「恢复（完全覆盖）中文用户词库失败！」，但文件本身没问题，多半是 **macOS 的隐私保护**造成的：

- 「文稿」「桌面」「下载」三个文件夹受隐私保护（TCC）。
- 搜狗自己导出的备份文件带有授权，输入法进程能读取。新生成或新下载的文件没有这个授权：在恢复对话框里选中文件时，系统只授权给了偏好设置程序，真正读文件的输入法进程读不到，于是直接报失败，连日志都不写。

解决办法（任选其一）：

- 在「系统设置 › 隐私与安全性 › 文件和文件夹」里允许搜狗输入法访问对应的文件夹。
- 把文件移到主目录下不受保护的文件夹里（例如 `~/搜狗词库/`），再去恢复。

## 原理

导出时**以原始备份为模板**，而不是从零生成文件：

- 保留的词条从原文件逐字节复制，词条里含义还不清楚的字段也原样保留。
- 文件头只改 4 个字段：条数、已用大小、零词频条数、校验和。文件头里那几个含义未知的统计值保持原值。
- 写出前会按搜狗的校验逻辑（`t_dictBase::CheckValid`）自检一遍。
- 一条都不删时，输出和原文件逐字节完全相同。

命令行 `rebuild` 支持新增词条，新词按备份里常见的词条格式构造，**属于实验性功能**，还没有在搜狗里实际验证过；新增后的总数不能超过原文件的容量。

网页版（`web/sogou.js`）和命令行版（`sogou_dict.py`）实现的是同一套逻辑，可以用 `node tools/check_web.js 备份.bin` 对拍，确认两边结果逐字节一致。

### 文件格式（SGPU）

| 偏移 | 含义 |
|---|---|
| `0x00` | 魔数 `SGPU` |
| `0x10` | 文件总长度 |
| `0x20` | 校验和：文件头各字段之和，不含它自己和 `0x28–0x37` |
| `0x28` | 最大的时序值（`0x2C–0x34` 是搜狗的统计值，不参与校验） |
| `0x38` | 索引起点、索引容量、条数、数据区起点、数据区容量、已用大小（6 个 uint32） |
| `0x54` | 词频为 0 的条数 |

索引是一组指向数据区的 uint32 偏移。每个词条的格式为：

```
词频 u16 | 时序 u32 | 3 字节标记 | 拼音字节数 u16 | 拼音码 u16×n | 扩展长度 u16 | 词字节数 u16 | 词(UTF-16LE) | 尾部
```

- 3 字节标记：前两字节几乎总是 `01 00`；第三字节是 3 或 2，为 2 的多是常用的短词，确切含义未知。
- 尾部通常是「字节数 u16 + 拼音码」，记录实际输入的拼音。多数与词条拼音相同；不同时多是用了简拼。简拼的编码从 842 开始：把所有音节前缀中本身不是音节的那些（b、be、bia、c、ch、cho……）加上 i、u、v，按字母排序依次编号。

时序在搜狗内部称为伪时间（pseudo time），导入时由 `t_dictPseudoRelation::GetRealTimeByPseudo` 借助用户目录里的 `sgim_gd_pseudorelation.bin` 换算成真实时间。
